# Projeto de Organizador de Imposto de Renda - Bootcamp Santander & DIO
Este repositório contém o projeto desenvolvido como parte do Lab do Bootcamp Santander - Excel com IA e Claude, uma iniciativa promovida pela DIO (Digital Innovation One) em parceria com o Santander. O objetivo deste laboratório é explorar os recursos nativos da ferramenta de planilhas eletrônicas da Microsoft: o Excel para a criação de planilhas inteligentes para boas análises e o gerenciamento de dados.

## Sobre o Projeto
O projeto consiste em um projeto de dashboard sobre uma base de dados fictícia de vendas de assinaturas da Xbox. Através da aplicação de recursos do próprio Excel, o projeto buscou desenvolver habilidades de organização da Workbook e pensamento crítico para dashboards que de fato sejam úteis para a tomada de decisões.

## Recursos do Excel Utilizados
Para a construção e o funcionamento eficiente desta planilha, foram utilizados diversos recursos e funcionalidades nativas do Microsoft Excel, tais como:

- **Organização da Workbook**: Criadas worksheets para abrigar a base de dados, cálculos para as dashboards e assets (recursos como imagens e paletas de cores).

- **Criação de Dados Personalizados**: Implementada para melhorar a visualização de dados especiais (como nº telefone e celular).

- **Validação de Dados**: Criação de listas suspensas e restrições de entrada para garantir a integridade e a padronização das informações inseridas.
